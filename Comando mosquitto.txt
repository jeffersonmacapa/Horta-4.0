comando para atribuir o IP do seu computador ao IP que será utilizado pelo MQQT BROKER
netsh interface portproxy add v4tov4 listenaddress=192.168.1.93 listenport=1883 connectaddress=127.0.0.1 connectport=1883
Comando para verificar se o IP foi realmente atribuido, dessa forma já deverá funcionar a comunicação do servidor BROKER com os sensores
netsh interface portprox show all
